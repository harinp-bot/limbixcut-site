# LIMBIX CUT — คู่มือติดตั้งเว็บ (ไม่ต้องเขียนโค้ด)

ไฟล์ในโฟลเดอร์นี้คือเว็บไซต์ตัวจริงพร้อมระบบแก้เนื้อหาแบบฟอร์ม (ไม่เห็นโค้ดเลย) ทำตาม
ขั้นตอนด้านล่างทีละข้อ ทุกขั้นตอนเป็นการคลิก/กรอกฟอร์มบนเว็บ ไม่ต้องพิมพ์คำสั่งใดๆ

สรุปภาพรวม: เว็บนี้ต้องใช้บริการฟรี 3 อย่างทำงานร่วมกัน
1. **GitHub** — ที่เก็บไฟล์เว็บ (เหมือนกล่องเก็บไฟล์ที่มีประวัติการแก้ไข)
2. **Netlify** — โฮสต์เว็บให้ออนไลน์ ฟรี
3. **DecapBridge** — ตัวกลางให้คุณล็อกอินเข้าหน้าแก้เนื้อหา (/admin) ได้โดยไม่ต้องรู้เรื่องโค้ด

(หมายเหตุ: เดิม Netlify มีระบบล็อกอินในตัวชื่อ "Git Gateway" ที่ทำให้ไม่ต้องใช้บริการที่ 3
แต่ Netlify ประกาศเลิกให้ตั้งค่าใหม่สำหรับเว็บที่เพิ่งสร้างแล้วในปี 2026 เราเลยต้องใช้
DecapBridge แทน เป็นบริการฟรีสำหรับเว็บเล็กๆ ทำหน้าที่แทนตัวเดิมเป๊ะ)

---

## ขั้นตอนที่ 1 — อัปโหลดไฟล์ขึ้น GitHub

1. ไปที่ [github.com](https://github.com) แล้วสมัครบัญชีฟรี (ถ้ายังไม่มี)
2. กดปุ่ม **New repository** (ไอคอน + มุมขวาบน → New repository)
3. ตั้งชื่อ เช่น `limbixcut-site` เลือก **Public** แล้วกด **Create repository**
4. ในหน้าที่เพิ่งสร้าง กด **uploading an existing file**
5. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `assets`, `content`, `admin` ด้วย) ไปวางในหน้านั้น
   แล้วกด **Commit changes**

   > ถ้า GitHub ไม่ให้ลากทั้งโฟลเดอร์ในทีเดียว ให้ลากทีละโฟลเดอร์ย่อยแทน (เข้าไปสร้างโฟลเดอร์
   > ก่อนด้วยการอัปโหลดไฟล์ 1 ไฟล์พร้อมพิมพ์ path เช่น `assets/logo-icon.png` ในช่องชื่อไฟล์)

## ขั้นตอนที่ 2 — เอาเว็บขึ้นออนไลน์ด้วย Netlify

1. ไปที่ [netlify.com](https://netlify.com) กด **Sign up** แล้วเลือก "Sign up with GitHub"
   (ใช้บัญชี GitHub ที่เพิ่งสร้างล็อกอินได้เลย ไม่ต้องตั้งรหัสผ่านใหม่)
2. กด **Add new site → Import an existing project**
3. เลือก GitHub แล้วเลือก repo `limbixcut-site` ที่สร้างไว้
4. หน้า deploy settings ปล่อยทุกช่องว่างไว้ตามค่าเริ่มต้น (ไม่ต้องใส่ build command เพราะ
   เว็บนี้เป็น static ล้วนๆ ไม่มีขั้นตอน build) แล้วกด **Deploy site**
5. รอสักครู่ Netlify จะให้ลิงก์ประมาณ `https://random-name-1234.netlify.app` — นี่คือเว็บของคุณแล้ว
6. (แนะนำ) ไปที่ **Site configuration → Domain management → Options → Edit site name**
   เปลี่ยนเป็นชื่อที่จำง่าย เช่น `limbixcut` จะได้ลิงก์ `limbixcut.netlify.app`

## ขั้นตอนที่ 3 — ตั้งค่าระบบล็อกอินแก้เนื้อหาด้วย DecapBridge

1. ไปที่ [decapbridge.com](https://decapbridge.com) สมัครบัญชีฟรี
2. ในแดชบอร์ด กด **Add site** แล้วกรอก:
   - Git provider: **GitHub**
   - Repository: `ชื่อบัญชี-GitHub-ของคุณ/limbixcut-site`
   - Admin URL: `https://ชื่อเว็บที่ตั้งไว้.netlify.app/admin/index.html`
3. ระบบจะขอให้คุณสร้าง **GitHub Personal Access Token** (คือรหัสอนุญาตให้ DecapBridge
   แก้ไฟล์ในนามคุณได้) — DecapBridge จะมีลิงก์พาไปหน้าสร้างโทเคนของ GitHub ให้อัตโนมัติ
   กด generate แล้วก็อปมาวางตามที่บอก
4. เสร็จแล้ว DecapBridge จะโชว์โค้ด `backend:` มาให้ก้อนหนึ่ง (หน้าตาประมาณ
   `name: proxy` พร้อม URL เฉพาะของคุณ) — ก็อปทั้งก้อนนั้นมา
5. กลับไปที่ GitHub → เปิดไฟล์ `admin/config.yml` ในเว็บ → กดไอคอนดินสอ (Edit) →
   ลบส่วน `backend:` เดิมที่อยู่บนสุด (มี comment กำกับไว้ชัดเจนว่าให้แทนที่ตรงไหน) แล้ว
   วางก้อนที่ก็อปมาแทน → กด **Commit changes** (Netlify จะดึงเวอร์ชันใหม่ขึ้นเว็บให้เองอัตโนมัติ
   ภายในไม่กี่นาที)
6. กลับไปที่ DecapBridge → แท็บ **Manage collaborators** → ใส่อีเมลของคุณ (และของทีม
   ถ้ามีคนอื่นช่วยอัปเดตเว็บ) → ระบบจะส่งอีเมลเชิญไปให้ตั้งรหัสผ่าน/ล็อกอิน

## ขั้นตอนที่ 4 — เข้าไปแก้เนื้อหา

1. เปิด `https://ชื่อเว็บของคุณ.netlify.app/admin/`
2. ล็อกอินด้วยบัญชีที่ตั้งไว้ในขั้นตอนที่ 3
3. จะเห็นเมนู 2 หมวด:
   - **ผลงาน (หน้า Work)** — เพิ่ม/ลบ/แก้โปรเจกต์ ใส่ชื่อ ประเภท ลูกค้า ปี ลิงก์วิดีโอ
     และอัปโหลดรูปปกได้เลย (ถ้าไม่ใส่รูป เว็บจะใช้สีพื้นตามหมวดให้อัตโนมัติ)
   - **ข้อมูลติดต่อ & สถิติหน้าแรก** — แก้อีเมล เบอร์โทร ที่อยู่ โซเชียล ตัวเลขที่โชว์บน Hero
     และตอนนี้แก้ได้เพิ่มอีก 2 อย่างคือ **โลโก้บนเมนู** (อัปโหลดไฟล์โลโก้จริงที่มีทั้งไอคอนและ
     ตัวหนังสือในตัวเองได้เลย ระบบไม่เติมคำว่า "LIMBIX CUT" ต่อให้ — ค่าเริ่มต้นตอนนี้คือไฟล์
     LC_Original ที่ให้มาจริงๆ ปรับสีให้อ่านออกบนพื้นดำแล้ว) กับ **รูปพื้นหลัง Hero** (อัปโหลด
     รูปถ่ายจริงแทนพื้นดำ+โลโก้จางๆ แบบเดิมได้ ถ้าไม่ใส่ก็ยังเป็นดีไซน์เดิม) ส่วนไอคอน X เล็กๆ
     ที่ใช้เป็นลายน้ำ/ท้ายเว็บ/favicon ยังคงที่ ไม่ได้ผูกกับช่องโลโก้นี้ (แจ้งผมได้ถ้าอยากแก้จุดนั้นด้วย)
4. แก้เสร็จกด **Publish** เว็บจะอัปเดตให้เองภายในประมาณ 1 นาที ไม่ต้องแตะโค้ดเลย

## ขั้นตอนที่ 5 — ผูกโดเมนที่คุณมีอยู่แล้ว

1. ใน Netlify ไปที่ **Site configuration → Domain management → Add a domain**
2. พิมพ์โดเมนของคุณ (เช่น `limbixcut.com`) แล้วทำตามที่ Netlify บอกให้ไปตั้งค่า DNS
   ที่ตัวจดทะเบียนโดเมนเดิมของคุณ (ปกติคือเปลี่ยน/เพิ่ม nameserver หรือ CNAME record)
3. รอ DNS อัปเดต (ปกติไม่กี่นาทีถึงไม่กี่ชั่วโมง) แล้วโดเมนจริงจะชี้มาที่เว็บนี้แทน Wix

## โครงสร้างไฟล์ (สำหรับอ้างอิง ไม่ต้องแก้เอง)

```
index.html          หน้าเว็บหลัก (โครงสร้าง+เนื้อหาคงที่)
style.css           ดีไซน์/สีทั้งหมด
script.js           ดึงข้อมูลจาก content/*.json มาแสดงผล
content/
  projects.json      รายการผลงาน — แก้ผ่านหน้า /admin เท่านั้น อย่าแก้ตรงๆ
  settings.json       ข้อมูลติดต่อ/สถิติ — แก้ผ่านหน้า /admin เท่านั้น อย่าแก้ตรงๆ
admin/
  index.html          ตัวโหลด Decap CMS
  config.yml           กำหนดฟอร์มที่เห็นในหน้า /admin
assets/
  logo-icon.png        โลโก้ X (จริงจากไฟล์ LC_Original ที่คุณส่งมา)
  logo-wordmark.png     โลโก้เต็ม LIMBIX CUT
  uploads/               รูปที่อัปโหลดผ่านหน้า /admin จะมาเก็บที่นี่อัตโนมัติ
```
